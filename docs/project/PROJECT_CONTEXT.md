更新：2026-10-16，版本 1.2.0，包含动作库重构、手机跟练与其他页面优化。用户最新要求“发布至GitHub”，已授权本次发布，沿用既有 main 与 Pages 工作流；部署结果以工作流为准。后续新优化仍只在本地进行，须新的上传指令才发布。

## 背景与范围

面向在家自行编排徒手与器械动作、按固定周训练日跟练的用户。参考同工作区“划船机”的 iOS 风格、暖金色、双主题和 iPad mini 7 横屏排版；交互参考本目录的创建计划与跟练图片。

P0：首次打开创建计划、热身/代谢训练/无氧训练三类动作库、触控/鼠标拖入与重排、插入/删除、每次只展开一个动作、参数快捷设置、计划周期与训练日、首页训练看板、全屏计时/计次、暂停/恢复、实际记录、本地持久化与基础离线。P1：主题、提示音、备份校验/预览/确认合并、PWA 更新提示。非目标：账号、云同步、AI、摄像头、动作识别、自动计数、设备连接和训练视频。

用户流程：设计计划 → 查看最近训练日 → 进入跟练。取消创建回首页；已有计划直接显示首页。

## 实现事实

- 首页两张卡片外框按视口固定。左卡通过与跟练相同的 buildStages 展开每一组动作及组间休息，不合并重复名称；动作卡仅显示编号和名称。双列逐行从左到右，列间距 44px 保持，行间距增为 36px，密集卡高 32px；1–3 段及窄屏纵向排列。每条虚线末端使用唯一 SVG marker 指向下一项，换行圆角回接。所有环节完整存在于列表中，超出后仅在模块内滚动，不再按“整屏塞下全部列表”压缩时间线。
- 右卡重构为训练看板：顶部突出下一次训练日期、相对时间与预计用时，有草稿时显示已跟练时间和段次；底部固定进入/继续跟练。中部展示本周已完成日程数和实际跟练用时，按上海时区统计实际结束记录，部分训练计入用时但不计入完成日。下部可切换接下来的 3 次安排和最近 3 次本计划训练记录，均为静态展示。移除原七日周历与周次浏览控件。
- 首页由 Home.tsx 与 TrainingDashboard.tsx 组织，样式集中于 src/ui/pages/Home.css，旧版首页专属规则已从共享 styles.css 移除，保留外框网格、通用控件、主题和其他页面样式。
- 数据备份导出按钮与文件选择使用统一 secondary 字号、字重、字体及高度；文件选择、预览确认与合并行为保留。

- 动作库采用热身、代谢训练、无氧训练三个入口，每库四组。原动作通过独立分组表重新归类，全部保留；静态注册表、展示入口和计划类型各自独立。来源为 ACE / NASM / NHS / AHA，具体见 product/动作库体系。
- 动作库默认仅显示名称。支持部位/动作分组/全部、徒手、器械交集筛选，空结果可重置；类型选择同时确定计划分类，切换重置库内筛选并保留已编排动作。
- 时长或次数、重量、组数、组间休息和有氧主观用力使用滑块/胶囊；删除滑块配套快选按钮。计量切换保留另一种数值；器械重量默认 0，需要自行选择。杠铃与部分器械上限按动作至 200 kg，旧哑铃上限仍 50 kg，步长 0.5 kg；明确杠铃总重与单只哑铃口径。主观用力为应用自定义 1–16 参考刻度，不是器械阻力档位。编辑控件、跟练目标/下一环节、计划与快照校验、备份读写共用范围常量；旧 1–10 数值原样保留，不做比例换算。
- Pointer Events 实现触控与鼠标拖动，计划区显示插入位置并边缘自动滚动；点击添加、选择插入位置、上/下移按钮提供等效操作。
- 新动作展开并在计划滚动区居中；空间允许时优先完整保留上一动作。此前动作折叠为核心摘要，每次只展开一个。动作库与计划模块各尺寸等宽；名称与周期占据紧凑顶部，周数/训练日同行，设置采用同行滑块与两列网格。删除计划统计与首次日期、展开动作的器械副标题，重量口径/部位/动作要点折叠到“动作参考”，底部只保留操作与错误反馈。编辑区域、动作库、首页计划、日程和跟练时间线各自滚动；页面边界固定。
- 按用户本次明确的紧凑要求，编辑器主控件 32px、胶囊 28px、插入入口 24px；保留可见标签、键盘焦点与等效点击/排序。此范围覆盖先前 44px 默认偏好，首页和跟练控件尺寸继续沿用原设计。窄屏、字体放大或短窗口以模块内滚动降级。
- 删除英文装饰标题、副标题和页脚标识，资料链接使用中文名称。字体集中为说明 12px、紧凑标签 13px、正文 14px及标题层级；计划名称输入为 16px。数值采用表格数字，字号放大时设置网格与计量行自动重排，避免数值与滑轨重叠。
- SVG 统一使用 24×24、2px 圆头描边、currentColor；整理日历与编辑图标，切换计划改用双向箭头，折叠参考改用 SVG 箭头。图标按钮提供中文辅助名称与关闭/排序等提示。
- 动作库按钮允许纵向触控浏览及缩放；横向手势或鼠标拖动编排，排序手柄保持纵向拖动。捕获主指针，取消、失去窗口焦点和取消键会结束拖动；取消后避免误添加。点击/键盘添加与上/下移始终提供等效操作。
- 弹窗关联中文标题，忙碌时禁用关闭；编辑器保存期间 inert 锁定，避免保存中继续修改而丢失变更。关闭后恢复入口焦点，入口消失或原焦点在背景时转向首页主要按钮。
- 反馈组件使用现有 React Portal 跟随当前原生弹窗，避免被顶层弹窗遮住；弹窗内反馈独立于滚动内容，普通反馈位于顶部，进入跟练清除上一页面的反馈。备份读取使用选择序号，只接受最新文件结果，预览显示文件名，关闭弹窗使未完成读取失效；安装异常有用户反馈并可重试。
- 计划 1–52 周，至少选择一个周训练日；首次训练为保存日当天起的下一次匹配日期，周期按该日所在周的周一锚定。跳过首次训练之前的日期，之后按周重复同一序列。编辑已有计划保留起始日期和已完成记录。
- 最近训练日先选择今天或未来最早的未完成日，无未来训练时显示最早待补练日；未训练的过往日期不会被自动标记完成。近期安排排除顶部已展示的训练日，优先显示后续未完成的未来安排，无未来安排时显示待补练日期。查看安排和切换记录不会开始训练或改变自动日期，唯一开始入口仍沿用原 nextTraining 规则。
- 训练结构复用首页的 FlowConnections 虚线组件，TrainingTimeline 将训练段排列为纵向卡片，当前项以暖金底色、边框和 aria-current 高亮。首尾预留真实滚动空间，进入、段次改变、恢复、尺寸或字号变化时自动居中；完成/跳过标记与快照逻辑保留。虚线根据实际卡片位置测量，并监听尺寸及首尾留白变化，避免调整窗口后偏移。
- 跟练右侧由 FollowDetails 组织，目标卡根据当前段展示用力/重量/次数或恢复时长，补充本组目标、器械、组次/待练组数和操作方式；下一环节卡展示目标、主观用力 /16、器械、既有动作要点及再下一环节预览。两张卡片外框保持原网格尺寸，内容仅在各卡内滚动。
- 跟练快照将多组动作展开为独立训练段，休息只插在组间。计时自动推进；计次只在用户确认后推进。每次 3 秒只用于预计时长，实际记录按前台计时。
- 跟练进度从左栏移到倒计时/计次用时数字下方。每个快照训练段等宽，沿用热身/有氧/力量/核心/恢复颜色；当前段有边框，跳过段有纹理。计时段显示当前段内比例，计次段等待明确确认。进度 100% 表示时间线已到末尾，完整训练仍由已有完成/跳过规则决定。删除“当前倒计时”、重复当前/待训练标签、英文副标题与通用提示，保留组次、动作要点、目标和按钮。辅助技术通过 timer 标签、progressbar 数值及阶段名称读取含义。
- 后台/锁屏/长于 2.5 秒的计时中断暂停，不追补后台时间。每 5 秒和阶段/暂停/退出时保存；突发进程终止可能损失最近约 5 秒。
- Web Locks 限制同时只在一个窗口操作跟练。训练中尽力申请屏幕常亮；未支持或未获准时仍可继续。提示音由用户开始操作解锁。
- 新计划不会删除此前计划，首页“更换计划”可切换已有计划；有跟练草稿时暂停创建/切换/编辑。其他窗口无法丢弃正在使用的草稿；存储故障可重试保存进度。
- 完整且未跳过的训练标记日程完成；提前结束/跳过只记部分训练。完整结束后由用户确认保存，写入以跟练 ID 幂等。

- 设置提供删除所有数据：先预览计划/记录/草稿数量，勾选理解恢复限制后确认。TrainingService 在跟练互斥锁内，通过 Repository 事务与预览时 revision 原子清空本应用训练状态；失败保留原数据，其他窗口正在跟练或确认后发生修改时拒绝。成功后仅重置本应用主题/提示音键；首次启动状态重置，revision 继续递增，离线资源缓存保留。继续跟练前重新读取状态，避免使用另一窗口已删除的草稿。

## 架构、数据和依赖

React/React DOM 19.2.6、TypeScript 5.9.3、Vite 8.0.16，复用划船机锁文件、版本和三个基础组件；未增加 UI/拖拽库。浏览器生产资源不依赖 CDN。原生 CSS/SVG、Pointer Events、IndexedDB、Service Worker、Web Audio、Web Locks 和 Wake Lock。

UI → TrainingService/SessionController → domain → Repository → IndexedDB。动作库静态定义与各库分组分离，bodyParts/equipmentKind/默认组间休息/负重上限均为内容元数据，不存入用户记录。数据库 `training-follow-db` v1，单个 `state` store 包含 schemaVersion/revision、计划、当前跟练、记录和首次启动标记。与划船机数据独立。计划具有 id/createdAt/updatedAt/version；跟练保存不可变动作快照。事务写入和 revision 防止编辑覆盖另一窗口改动。升级不删库。

LocalStorage 仅保存主题和提示音配置。JSON 备份包含应用标识、版本、导出时间和完整状态，最大 5 MB，校验字段/范围/日期/关联/重复。导入预览后原子合并新 ID，同 ID 保留本机版本；未结束跟练不导入、不覆盖本机。错误保留原数据。

## PWA 与布局

生产构建生成按内容哈希版本的 SW，安装预缓存相对资源；导航 Network First + 缓存回退，清单内静态资源 Cache First。只清理本应用前缀缓存，等待更新需用户点击，存在跟练草稿时不更新。

桌面本地预览端口 5190，默认绑定 127.0.0.1。`--lan` 可供同网浏览器预览；iPad 上 HTTP 局域网地址不具备完整 PWA 安全上下文，需要受信 HTTPS 才能验证离线与安全计时锁。详见 README。

横屏目标 1133×744 / DPR 2；兼容 1133×650 浏览器栏高度、竖屏、分屏、手机和短窗口。iPad 首页双卡、编辑左右模块、跟练三栏；手机竖屏优先核心信息，首页训练看板在前，编辑器切换全宽工作区，跟练按参考布局展示完整时间线与动态目标。各模块内部滚动。

0.3.1 的改动仅涉及 UI 和进度展示计算，无新依赖、存储迁移或训练完成规则变更；原计划、草稿快照与备份继续读取。

0.3.2 未改动数据库、备份、训练快照与完成规则。新增交互保护与设计 Tokens，复用现有 React/React DOM 和浏览器能力，无新增包。
