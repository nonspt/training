# 全应用设计与交互审查 · 0.3.2

日期：2026-10-14。审查结论：PASS WITH ISSUES，浏览器范围通过，真实 iPadOS Safari、VoiceOver 和安装许可待验收。

## 覆盖与设计调整

检查空首页/已有计划首页、周历、计划列表、创建/编辑、动作库筛选、设置与备份、跟练与汇总，以及反馈、忙碌和错误路径。保留划船机应用的暖金色与双主题、iPad 横屏、等宽编辑模块、紧凑控件和模块内滚动。

- 删除英文装饰标题、副标题和页脚；资料链接中文化，页面保留功能名称和必要状态。
- 说明 12px、标签 13px、正文 14px、计划名称输入 16px，标题保持清晰层级；数字采用表格数字。字体放大自动重排计量行/设置网格，数值不覆盖滑轨。
- SVG 使用 24×24、2px 圆头描边与 currentColor。整理日历点阵、编辑图标和计划切换双向箭头，折叠参考统一 SVG；图标按钮保留中文辅助名称与提示。
- 移除装饰页脚，减少首页顶部空白；首页双模块对齐，设置卡片间距一致，反馈独立于弹窗滚动内容。

## 已确认问题与修复

| 编号 | 问题与证据 | 修复及验证 |
| --- | --- | --- |
| UI-01 | 空首页、周历副标题和页脚存在英文装饰文字 | 删除；逐页检查标题/副标题无英文内置文本 |
| UI-02 | 字体分散，竖屏跟练组次说明仅约 10.9px | 集中 Tokens，统一 caption；横/竖/短窗及 200% 字号检查 |
| UX-01 | 在动作按钮上纵向滑动，动作库 scrollTop 仍为 0 | 允许纵向浏览/缩放，横向启动拖放；实际触控后 scrollTop 164.8px，未误添加 |
| UX-02 | 拖动缺少指针捕获与取消键复位 | 捕获主指针、按 ID 处理取消，失焦/取消键清理；横向拖入与取消不误添加通过 |
| UX-03 | 快速选择慢文件再选错误文件，出现旧预览与新错误并存 | 选择序号隔离异步结果、卸载失效；最新错误无旧预览，原数据保留，成功合并去重 |
| UX-04 | 保存处理中仍可修改动作，后续改动可能未进入保存快照 | 保存期间 inert 锁定，关闭/取消禁用；占用 IndexedDB 事务验证忙碌保护 |
| A11Y-01 | 创建弹窗有可见标题但无辅助名称；首次保存焦点回背景 | aria-labelledby 关联，关闭恢复入口或主要按钮；命名查询与键盘焦点通过 |
| UX-05 | 原生弹窗遮住外层反馈，保存反馈进入跟练后遮住操作 | Portal 将反馈放入当前弹窗；全局反馈置顶部，进入跟练清除旧消息；可见与层级检查通过 |
| UX-06 | 安装请求失败会产生未处理拒绝 | 反馈安装未完成及重试路径；模拟失败/重试通过，运行时错误为 0 |
