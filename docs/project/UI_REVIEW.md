## 覆盖与设计调整

检查空首页/已有计划首页、周历、计划列表、创建/编辑、动作库筛选、设置与备份、跟练与汇总，以及反馈、忙碌和错误路径。保留划船机应用的暖金色与双主题、iPad 横屏、等宽编辑模块、紧凑控件和模块内滚动。

- 删除英文装饰标题、副标题和页脚；资料链接中文化，页面保留功能名称和必要状态。
- 说明 12px、标签 13px、正文 14px、计划名称输入 16px，标题保持清晰层级；数字采用表格数字。字体放大自动重排计量行/设置网格，数值不覆盖滑轨。
- SVG 使用 24×24、2px 圆头描边与 currentColor。整理日历点阵、编辑图标和计划切换双向箭头，折叠参考统一 SVG；图标按钮保留中文辅助名称与提示。
- 移除装饰页脚，减少首页顶部空白；首页双模块对齐，设置卡片间距一致，反馈独立于弹窗滚动内容。
