# 已知限制

1.2.0 的动态目标、分类改名与手机页面优化已获本次发布授权，沿用 main 与 Pages；部署以工作流结果为准。手机专用布局为 ≤600px 且竖屏，iPad 原布局保留。验证采用隔离 Edge Chromium 与合成数据，真实 iPhone Air / iPadOS Safari 仍待实机验收。

手机首页现固定下一次训练、周统计和计划摘要，仅看板两列列表与完整时间线滚动。大字号时固定摘要采用有上限的缩放以保留滚动空间；列表和操作文字继续放大。近期安排仍按既有规则展示后续最多三次日期，记录仍为最近三次，未增加日程或记录数量。

当前本地动作库已增加 11 个热身动作。包含这些新动作 ID 的备份需要具有本次注册表的构建读取；回滚时需保留新动作注册表兼容补丁，不通过清库回滚。三入口只是浏览分类，热身与主训练可编入同一份计划。

1.1.0：新版导出为 v2，包含新结构的数据须由 1.1.0 及以上读取。旧离线 worker 未完成更新时会阻止新结构写入并提示更新，原计划保留；旧计划可继续使用。10 组等较长表格在所属动作内滚动，大字号/短窗口仍按模块内滚动降级。

2026-10-16 · 当前版本 1.1.0，已获上传授权；本次不宣称已完成线上复核。

- 尚未进行真实 iPad mini 7 / iPadOS Safari、主屏安装、VoiceOver、提示音与锁屏实机验收；自动验证使用 Chromium 的分辨率、DPR 和触控参数模拟。
- iPad 访问普通 HTTP 局域网地址只可预览界面；完整 PWA 与安全跟练需要受信 HTTPS。桌面 localhost 可使用安全上下文。HTTPS 证书路径及 LAN 启动方式见 README。
- 跟练采用前台计时。隐藏/锁屏/长间隔会暂停，不包含后台时长。突发关闭进程可能损失最近约 5 秒，但计划、已保存记录和此前快照会保留。
- 不包含动作视频或自动动作/次数识别；计次以用户确认作为完成依据。预计时长以每次 3 秒估算，与实际用时分开。
- 声音和屏幕常亮受平台能力、权限、静音模式和电源策略影响，不能保证始终可用。
- 本地单源数据；不同浏览器、端口、HTTP/HTTPS 的数据不共享，需要备份迁移。浏览器清除网站数据会清除本机训练数据，应定期导出。
- 已支持按星期分别设计方案；未提供逐周自动递增负荷和逐组实际训练记录。
- 手机竖屏（≤600px）已按新布局显示完整时间线，数值与下一段文案精简；短窗口或大字号时仅模块内部滚动。iPad 横竖屏和手机横屏保留原布局。真实 iPhone Air Safari/主屏安装仍需实机确认。
- iPad 紧凑编辑器保留原控件与双栏；手机竖屏改用可切换的全宽计划/动作库，触点至少 44px。所有设置与上一动作同时可见的验收范围仍为 1133×744/650 横屏；更窄、短窗口或字体放大后，在模块内滚动查看。
- 0.3.2 触控滚动/拖放、弹窗焦点、备份选择竞态与安装异常通过隔离 Chromium 验收；安装异常使用模拟失败/重试，不能代替 Safari 安装和真实系统许可验证。
- 上限：30 份计划、每个训练日方案 100 个动作、动作 10 组、备份 5 MB。超出限制会阻止保存/导入，保留原数据。

新增动作/较大负重备份需由 0.2.0 或兼容补丁读取，不能直接回退至 0.1.0；旧备份继续可导入。

真实设备连接不在本版范围。GitHub Pages 发布状态见 RELEASE.md；本地数据不会自动出现在正式站点，需导出/导入备份。

首页时间线按实际跟练顺序逐组展开，包含组间休息和重复动作，不再承诺 12 个计划项目等内容全部同屏。所有动作卡仅显示名称和序号，完整内容在固定卡片内滚动。训练看板仍提供接下来三次安排/最近三次记录。窄屏与 200% 字号同样采用模块内滚动。

- 含 11–16 主观用力目标的备份需用 1.0.5 及以上读取；当前线上 1.0.0 不支持。旧数值不自动缩放。回滚请保留新版可读备份。
- 删除数据会清空本应用的本机计划、记录、草稿并重置主题/提示音，无法撤销；已有导出备份可重新导入。其他窗口正在跟练或确认后数据改变时拒绝删除，须退出跟练或重新核对范围。
