# 项目开发规则

遵循用户提供的 Vibe Coding 长期约定。开始修改先读 `docs/project/PROJECT_CONTEXT.md`，再按任务查阅共享规范：`D:/OpenAIData/CodexHome/developer-standards/vibe-coding/docs/standards/`。共享规范不存在时检查工作区“开发规范”的镜像，不重复制造规范副本。

保留当前 React/TypeScript、分层、暖金色/双主题、统一 SVG 和独立数据库。模块边界固定，内容只在所属模块内滚动。修改时间与次数逻辑必须覆盖计时/计次、暂停/恢复和部分完成路径；修改数据必须覆盖备份与事务失败保护。

用户于 2026-10-14 明确授权将当前版本定义为正式版 V1.0，并上传到已创建的 `nonspt/training` 仓库、启用 GitHub Pages；此前仅限本地的要求已被这次发布请求覆盖。发布只包含项目源码、公共资源、锁文件、测试、文档和构建配置，不上传依赖目录、测试产物、参考图片、证书、秘密或用户备份。测试使用隔离浏览器和合成数据，不清除真实用户数据。版本升级不删库，缓存清理只使用本应用前缀。

当前最新范围：用户于 2026-10-16 明确授权将当前 1.0.5 版本直接上传 GitHub，覆盖此前暂不发布的限制；沿用现有 main 分支与 Pages 工作流。用户要求上传后不复核线上版本，仅告知上传是否成功。

首页布局约束：计划与训练看板卡片的外框保持固定，不能根据内容数量缩短；动态尺寸只作用于内部列表的行高、间距和留白。超出容量的内容在模块内滚动。
