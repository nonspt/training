# 动作库体系 · 1.2.0

2026-10-16。1.2.0 按用户确认设置热身、代谢训练、无氧训练三个并列入口。用户已明确要求发布至 GitHub，本次纳入 1.2.0。

| 入口 | 展示项数 | 分类 |
| --- | ---: | --- |
| 热身 | 26 | 泡沫轴、关节活动、核心激活、动态拉伸 |
| 代谢训练 | 41 | 长时慢速长距代谢训练、配速/节奏训练、间歇训练、恢复及拉伸 |
| 无氧训练 | 65 | 上肢推、上肢拉、下肢推拉、核心 |

三库共 132 个展示项，其中死虫、鸟狗、臀桥、平板与侧平板这 5 个动作在热身与无氧库共享，共 127 个不同可见动作。原有 116 个不同动作全部保留，新增 11 个热身动作；注册表共 128 项，旧“弹力带训练”仍仅用于旧记录兼容。

## 热身

- 泡沫轴（6）：小腿、大腿前侧、大腿内侧、臀部、背阔肌、上背部。
- 关节活动（7）：肩部绕环、踝关节活动、髋铰链练习、肩胛俯卧撑、弹力带拉开、髋关节绕环、胸椎旋转活动。
- 核心激活（5）：死虫式、鸟狗式、臀桥、平板支撑、侧平板支撑。
- 动态拉伸（8）：原地踏步、脚跟前点、交替提膝、浅蹲热身、毛毛虫爬行、前后摆腿、手臂动态开合、行进弓步上伸。

新增项为 6 个泡沫轴动作、髋关节绕环、胸椎旋转活动、前后摆腿、手臂动态开合、行进弓步上伸。共享的核心激活动作沿用原 ID、计量能力和类别，不复制为不兼容的新动作。

## 代谢训练

- 长时慢速长距代谢训练（7）：快走、慢跑、跑步机快走/慢跑、健身车骑行、划船机稳态划行、椭圆机训练。
- 配速/节奏（10）：坡度快走、有氧踏步、侧向踏步、踏步开合、侧向滑步、有氧拳击、踏板上下步、滑冰侧跨步、跳绳、登阶机训练。
- 间歇（13）：跑走交替、健身车/划船机/跑步机间歇、开合跳、高抬腿跑、后踢腿跑、波比跳、踏步波比、登山者、深蹲跳、跳箱、战绳交替波浪。
- 恢复及拉伸（11）：站立休息、慢走放松、缓骑放松、轻松骑行、小腿/大腿前侧/腿后侧/胸部/背阔肌/髋屈肌拉伸、婴儿式放松。

恢复集中到代谢库，因此无氧训练计划也通过此入口添加恢复动作。分组用于浏览编排，具体训练方式仍取决于用户设定的节奏、时长和用力；静态标签不把某动作的供能方式或训练强度固定下来。用户已将原 LSD 展示名简化为“长时慢速长距代谢训练”，分组 ID `a-lsd` 保留。原有动作名称中的“有氧”保留，用于稳定识别旧动作。

## 无氧训练

- 上肢推（15）：卧推、俯卧撑及变体、推胸/夹胸、肩推/侧平举、三头训练与深蹲推举。
- 上肢拉（13）：引体、下拉、划船、反向飞鸟、面拉、弯举与哑铃支撑划船。
- 下肢推拉（25）：深蹲、硬拉、弓步、腿举/腿屈伸/腿弯举、提踵、臀桥/臀推、髋主导与平衡动作、壶铃摆荡、深蹲弯举、弓步转体。
- 核心（12）：支撑、卷腹、抗旋转、平板撑起/触肩、负重行走与熊爬。

三大项按动作模式重组：杠铃卧推在上肢推，杠铃深蹲和硬拉在下肢推拉。复合动作按主要编排用途放入一组，同一库不重复。

## 筛选、编辑与布局

部位标签、分组、徒手/器械筛选取交集；切换入口重置筛选，保留计划动作、分日编排与所有已填参数。空结果可重置。三个入口在窄屏内按等宽网格换行，模块外框不随内容变化，动作仍只在库内滚动。

热身入口是浏览状态，不会把计划类型写成 warmup；从代谢或无氧切到热身后保存，沿用原计划类型。旧 mixed 计划进入热身后保存仍为 mixed。已有 aerobic/strength/mixed 标识继续兼容；全应用 aerobic/cardio 的分类展示改为“代谢训练”。

动作默认值为可编辑示例，负重输入范围和旧默认值保持原样。杠铃填写总重，哑铃按单只器械口径；参考资料在动作设置的“动作参考”内查看。

## 来源和整理边界

原动作来源及说明见“动作资料.md”与各动作 source 字段。新增泡沫轴参考 [NASM 泡沫轴整理](https://www.nasm.org/resource-center/blog/recovery/foam-rolling-and-self-myofascial-release-the-trainer-application-guide)、[小腿](https://www.nasm.org/resource-center/exercise-library/foam-roll-calves)、[内收肌](https://www.nasm.org/resource-center/exercise-library/foam-roll-adductors)、[背阔肌](https://www.nasm.org/resource-center/exercise-library/foam-roll-latissimus-dorsi)；动态热身参考 [ACE 动态热身](https://www.acefitness.org/continuing-education/prosource/may-2015/5379/do-it-better-dynamic-warm-ups/)。

名称、提示和分组属于产品整理，参考链接不是机构对本应用训练计划的背书，也不表示每个变体都在链接中单独教学。未转载图片、视频或长篇教学。

## 数据与回滚

无新增依赖，不改变数据库、schemaVersion 1/2、备份格式、计时器或跟练完成规则；不删除或迁移用户数据。全部旧 ID、名称、计量能力、默认参数保持不变，既有计划和正在进行的不可变快照继续可读。静态动作的 types 元数据按新库归属计算，热身动作适用于两种主训练类型。

新版可读取旧 v1/v2 备份。含 11 个新增动作 ID 的备份需要具有本次注册表的构建；回滚到未包含这些 ID 的版本会拒绝读取，需保留新注册表兼容补丁并先导出备份，不通过清库回滚。
